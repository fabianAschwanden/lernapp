Lernen mit dem Karteikasten (Leitner-Prinzip)

Jede Frage liegt in einem von fünf Fächern. Beantwortest du sie richtig, rückt sie ein Fach weiter und kommt später wieder. Eine falsche Antwort schickt sie zurück in Fach 1. Eine neue Frage, die du auf Anhieb richtig beantwortest, springt direkt in Fach 2.

@for (z of leitner; track z.fach) { }
Fach Wieder fällig
{{ z.fach }} {{ z.abstand }}

Kurz vor der Prüfung rückt die App alles zusammen: Am Tag vor dem Prüfungsdatum ist jede Frage nochmals fällig.

Note der Probeprüfung

Note = 1 + 5 × erreichte Punkte ÷ maximale Punkte. Volle Punktzahl ergibt eine 6, die Hälfte eine 3,5; ab 4 ist die Prüfung genügend.

Lernstand pro Lernziel

Jede Frage gehört zu einem Lernziel. In der Lektionsübersicht siehst du pro Lernziel, wie viele Fragen schon sitzen — so erkennst du, wo du noch üben musst, und kannst gezielt dieses Lernziel lernen.
