Was gespeichert wird

  • Von deinem Google-Konto nur die E-Mail-Adresse und den Namen — für die Anmeldung.
  • Deine eigenen Lektionen, dein Lernstand, die Probeprüfungen, deine Rückmeldungen zu Prüfungen und deine Einstellungen — auf dem Server der Lernapp in der Schweiz, damit sie auf all deinen Geräten gleich sind.
  • Ein Cookie, das dich angemeldet hält (90 Tage ab der letzten Nutzung, höchstens ein Jahr, nur für die Lernapp).
  • Dein Claude-API-Schlüssel (falls du einen einträgst) bleibt nur auf deinem Gerät und geht nie an den Server der Lernapp.

Beim Abmelden werden deine Daten von diesem Gerät entfernt; auf dem Server bleiben sie, bis du sie in den Einstellungen löschst.
